# Features Detailed

## Launch Tracking

- merged upcoming launch feed from SpaceX and Launch Library 2
- live-launch window based on approximately `±2 hours`
- next-launch spotlight card

## Stream Access

- direct webcast links when providers expose them
- ranked launch-intel candidates from provider links and YouTube
- provider-channel fallback links
- YouTube, Reddit, and X search fallback links

## Launch Geography

- integrated launch-sites map inside the upcoming-launch section
- telemetry globe with active-pad follow mode
- expandable modal state
- explicit close controls for the expanded map

## History

- recent SpaceX past launches
- success and failure stats
- search, status, and sort controls adapted for historical data

## Facts and Branding

- rotating header ribbon fed by SpaceX rocket stats and NASA APOD
- active logo in `public/newlogo.jpeg`
- green mission-control visual system

## Notifications and Calendar

- browser permission prompt
- local scheduling for 1-hour, 10-minute, and live notifications
- Google Calendar links
- `.ics` downloads
